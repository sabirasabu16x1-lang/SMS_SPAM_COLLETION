# SMS_SPAM_COLLETION
SMS Spam Detection Using Machine Learning

This project uses Machine Learning to identify and classify SMS messages into Spam and Ham (Normal).

Tools Used: Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.

Algorithms Used:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

Process:

- Dataset loading and cleaning
- Data visualization
- TF-IDF vectorization
- Feature selection
- Model training and testing
- Performance evaluation

Result: Random Forest achieved the highest accuracy of 97.49% in our experiment.

Conclusion: This project demonstrates how Machine Learning helps detect unwanted SMS messages and classify them automatically.
